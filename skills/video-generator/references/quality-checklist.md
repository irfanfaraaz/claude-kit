# Quality Checklist

Run through these **before** sending the user the preview URL. Fix any failure.

- [ ] **Mute test** — Story is clear with sound off? Visual hierarchy and pacing carry the message.
- [ ] **Squint test** — When squinting, is the hierarchy obvious? Headlines vs body, primary vs secondary.
- [ ] **Timing test** — Motion feels natural, not robotic? Varied pacing; springs/easing where appropriate.
- [ ] **Consistency test** — Similar elements (e.g. feature cards, titles) use the same animation style and timing.
- [ ] **Slideshow test** — It does **not** look like PowerPoint: no repetitive fade-to-black, no centered bullet blocks only.
- [ ] **Loop test** — If the video is intended to loop, the end connects smoothly to the start.
- [ ] **Brand test** — If featuring a product, brand colors and assets from Firecrawl are used; no generic purple gradient unless brand or user requested.
- [ ] **Icons** — No emoji; all icons from Lucide React.

If any item fails, update the Remotion source and re-check. Only then share the tunnel URL or render.
