## Color System

### Core Palette

| Role | Token | Hex | Use |
|------|-------|-----|-----|
| Background | `--background` | `#ffffff` | Page/app background |
| Surface | `--surface` | `#f7f4ee` | Cards, panels, modals |
| Text Primary | `--text-primary` | `#0a0a0a` | Headings, body text |
| Text Muted | `--text-muted` | `#6b6b6b` | Captions, placeholders |
| Accent | `--accent` | `#c8f135` | CTAs, links, focus rings |
| Border | `--border` | `#333333` | Dividers, card borders |

### Extended Palette

- **color-primary:** `#497d00`
- **color-rule:** `#d8d4cc`
