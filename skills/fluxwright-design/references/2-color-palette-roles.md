## 2. Color Palette & Roles

| Token | Hex | Role | Use |
|---|---|---|---|
| tw-ring-offset-color | `#ffffff` | background | Page background, darkest surface |
| color-bg | `#f7f4ee` | surface | Card and panel backgrounds |
| color-fg | `#0a0a0a` | text-primary | Headings and body text |
| color-muted | `#6b6b6b` | text-muted | Captions, placeholders, secondary info |
| color-muted | `#9a9a9a` | text-muted | Captions, placeholders, secondary info |
| color-rule | `#333333` | border | Dividers, card borders, outlines |
| color-primary | `#c8f135` | accent | CTAs, links, focus rings, active states |
| color-primary | `#497d00` | unknown | Palette color |
| color-rule | `#d8d4cc` | unknown | Palette color |
